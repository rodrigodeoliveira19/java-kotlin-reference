# Task 1 - Tecnologias

## Objetivo
Estabelecer a base tecnológica da aplicação para importação de CSV em Java com Micronaut, PostgreSQL e AWS S3.

## Requisitos
- Java LTS compatível com a versão estável escolhida do Micronaut.
- Micronaut Framework.
- Micronaut Data JPA.
- Hibernate ORM.
- PostgreSQL.
- Flyway para migrations.
- AWS SDK for Java v2.
- Apache Commons CSV.
- JUnit e Mockito.
- Testcontainers para testes de integração com PostgreSQL.

## Restrições
- Não utilizar Spring Boot.
